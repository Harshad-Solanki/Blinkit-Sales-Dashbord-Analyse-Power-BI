# 🛒 Blinkit Sales Dashboard – Power BI

An interactive **Power BI Sales Dashboard** created to analyze Blinkit's sales performance, product categories, outlet performance, and key business metrics.

## 📊 Project Overview

This project transforms Blinkit sales data into an interactive Power BI dashboard that provides a clear view of overall business performance.

The dashboard enables users to explore sales trends and compare performance across different **product categories, outlet types, outlet sizes, and locations**.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Modeling
- Data Visualization

## 📌 Key Features

- Total Sales and other important KPIs
- Sales analysis by product category
- Outlet-wise sales performance
- Outlet size and outlet type analysis
- Analysis of item visibility and ratings
- Interactive filters and slicers
- Dynamic charts and visualizations
- Business-focused dashboard design

## 🎯 Objectives

- Analyze overall sales performance
- Identify high-performing product categories
- Compare different outlet types and sizes
- Understand sales trends and patterns
- Create an interactive dashboard for business decision-making

## 💡 Skills Demonstrated

**Power BI | DAX | Power Query | Data Cleaning | Data Modeling | Data Analysis | Data Visualization | Dashboard Development | Business Intelligence**

This project was developed as a portfolio project to demonstrate practical skills in **Power BI, data analysis, data transformation, and business intelligence dashboard development**.
